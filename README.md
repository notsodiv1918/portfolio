# Divyansh Rangari Portfolio

React and Vite portfolio styled as a live design file edited by agents.

## Run locally

```
npm install
npm run dev
```

## Build

```
npm run build
npm run preview
```

## Deploy on Vercel

Import the repository on vercel.com. Framework preset: Vite. Build command: `npm run build`. Output directory: `dist`.

## Structure

- `src/components` page sections as React components
- `src/engine.js` agent cursors, build-in animation, command palette, layers, comments, export and bug hunt
- `src/styles.css` all styles and theme tokens
- `public/assets` photos and resume files
